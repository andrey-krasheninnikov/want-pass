# Local integrations and bounded MCP / Локальные интеграции и ограниченный MCP

UI, CLI, native integrations and MCP use the same authorization boundary. Want Pass MCP provides permitted metadata, confirmed storage and bounded adapter actions without a get-secret response, arbitrary shell or arbitrary destination; the first complete action uses the GitHub adapter. A third-party process explicitly granted credentials is a separate trusted recipient, whose behavior cannot be guaranteed by Want Pass response policy.

UI, CLI, нативные интеграции и MCP используют общую границу авторизации. Want Pass MCP предоставляет разрешённые метаданные, подтверждаемое сохранение и ограниченные действия адаптеров без get-secret, произвольного shell или произвольного назначения; первое законченное действие использует адаптер GitHub. Сторонний процесс, которому явно переданы credentials, является отдельным доверенным получателем, чьё поведение не гарантируется политикой ответов Want Pass.
