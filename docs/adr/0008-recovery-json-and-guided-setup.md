# Recovery JSON and guided setup / JSON восстановления и мастер настройки

The vault file remains V2. V1/V2 APIs retain their contracts; V3 adds JSON, authenticated recovery validation, draft revision and regeneration. No migration or reset is required. First setup has six steps: appearance, password, password hint and saved-password acknowledgment, save phrase, phrase location with two acknowledgments, then one screen for three word checks. Recovery replaces appearance with the old phrase. Configured appearance is omitted from later creation. Back preserves values; password edits clear its acknowledgment.

Файл сейфа остаётся V2. API V1/V2 сохраняют контракты; V3 добавляет JSON, проверку доступа при восстановлении, revision черновика и перегенерацию. Миграция или сброс не требуется. Первая настройка состоит из шести шагов: оформление, пароль, подсказка и подтверждение сохранения пароля, сохранение фразы, место хранения с двумя подтверждениями, затем один экран проверки трёх слов. Восстановление заменяет оформление прежней фразой. При повторном создании настроенное оформление пропускается. Возврат сохраняет значения; изменение пароля сбрасывает его подтверждение.

All export channels carry identical compact UTF-8 JSON with string keys 1 through 24 and English BIP39 word values in phrase order. The filename is `want-pass-recovery.json`. Passwords, hints and extra metadata are excluded. Native parsing limits input to 16 KiB and rejects duplicate, missing or extra keys, non-string values and words outside the dictionary. Reordered keys and repeated words are valid. Plain 24-word phrases remain accepted. Multiline input preserves separators. The existing vault is authenticated before leaving recovery input.

Все способы экспорта содержат одинаковый компактный UTF-8 JSON с ключами-строками от 1 до 24 и английскими BIP39-словами в порядке фразы. Имя файла: `want-pass-recovery.json`. Пароль, подсказки и лишние метаданные исключены. Native парсер ограничивает ввод 16 KiB и отвергает повторные, пропущенные и лишние ключи, значения других типов и слова вне словаря. Произвольный порядок ключей и повторяющиеся слова допустимы. Обычные фразы из 24 слов также принимаются. Многострочный ввод сохраняет разделители. Подлинность существующего сейфа проверяется до выхода из ввода восстановления.

The save step requires a successful copy, file write or explicit QR acknowledgment. The user selects all three words and submits them together. Rust checks the answers against the current draft before writing the vault. A wrong answer returns to the same phrase and clears the export gate, phrase acknowledgments and all answers. The password and its acknowledgment remain. The draft revision stays valid, so an exported copy of that phrase still matches the draft.

На шаге сохранения требуется успешное копирование, запись файла или явное подтверждение QR. Пользователь выбирает все три слова и отправляет их вместе. Rust проверяет ответы по текущему черновику до записи сейфа. Неверный ответ возвращает к той же фразе и сбрасывает отметку экспорта, подтверждения хранения и ответы. Пароль и подтверждение его сохранения остаются. Версия черновика не меняется, поэтому ранее сохранённая копия фразы соответствует черновику.

The compact QR retains a white quiet zone, square modules and primary finder marks without an embedded logo. Its saved action records the QR acknowledgment and satisfies the save gate. The dial reflects the controller's monotonic five-minute idle deadline, renewed by activity. Rendering never grants access. A closed dial opens password entry with direct recovery. Typed effects deliver confirmed copy, file-write and manual-lock feedback. Secret overlays close on lock, close or revision replacement. Want Allure 1.1.1 supplies compact-dialog and hidden-pause-control options while preserving reduced motion and inactive suspension.

Компактный QR сохраняет белую quiet zone, квадратные модули и primary-маркеры без встроенного логотипа. Кнопка «Я сохранил» подтверждает сохранение QR и открывает следующий шаг. Замок отражает монотонный срок пяти минут бездействия контроллера, продлеваемый активностью. Отрисовка не предоставляет доступ. Закрытый замок открывает пароль с прямым восстановлением. Типизированные effects передают подтверждённые уведомления о копировании, записи файла и ручной блокировке. Секретные overlays закрываются при блокировке, закрытии или смене revision. Want Allure 1.1.1 предоставляет компактный диалог и скрытие кнопки паузы с сохранением reduced motion и остановки неактивного экрана.
