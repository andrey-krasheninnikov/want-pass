# Platform and release-channel capabilities / Возможности платформ и каналов релиза

Release claims use a tested capability matrix per platform, browser and distribution channel. Direct macOS and Mac App Store builds may differ; store builds use the store update route, while direct builds verify their update metadata and artifacts. Published versions remain immutable, and unsupported provider APIs or import routes remain explicit research results rather than promised parity.

Заявления о релизе используют проверенную матрицу возможностей по платформам, браузерам и каналам. Прямая macOS-версия и Mac App Store могут отличаться; магазинные сборки обновляются своим магазином, прямые проверяют метаданные и артефакты обновлений. Опубликованные версии неизменяемы, а неподдержанные API провайдера или маршруты импорта остаются явными результатами исследования вместо обещания равенства возможностей.
