# Vault V2, public hints and setup / Сейф V2, открытые подсказки и настройка

This decision supersedes ADR 0006 for the file layout, current setup policy and recovery export. The accepted clean-stand workflow uses native bundle ID `foundation.want.pass`. Persisted V1 files are rejected without conversion or deletion; the old bundle namespace is preserved.

Это решение заменяет ADR 0006 в части раскладки файла, правил текущей настройки и recovery export. Согласованный чистый стенд использует native bundle ID `foundation.want.pass`. Файлы V1 отвергаются без преобразования или удаления; старый bundle namespace сохраняется.

The owner chose hints visible before unlock. Both optional hints therefore remain plaintext, with a limit of 256 Unicode scalars and 1,024 UTF-8 bytes each. They must not contain passwords or recovery words. Parsing is bounded before the KDF, and both key slots authenticate the complete public metadata. An unauthenticated hint may be displayed before unlock but cannot grant access. All other document metadata remains encrypted.

Пользователь выбрал подсказки, видимые до разблокировки. Обе необязательные подсказки поэтому хранятся открыто, с лимитом 256 Unicode scalars и 1024 UTF-8 байта каждая. Пароль и recovery-слова в них не указываются. Парсинг ограничен до запуска KDF; оба key slots аутентифицируют все публичные метаданные. До разблокировки подсказка может отображаться без проверки подлинности, но не предоставляет доступ. Остальные метаданные документа остаются зашифрованными.

The container magic stays `57 50 41 53 53 00 01 00`; format is `u16 = 2`, suite and KDF profile remain `1`. The first 46 bytes retain their ADR 0006 fields. Bytes `46..48` and `48..50` contain little-endian UTF-8 byte lengths for password and recovery-location hints. Hint bytes follow in that order. Let `B = 50 + passwordHintBytes + recoveryHintBytes`. Password nonce/slot occupy `B..B+72`, recovery nonce/slot `B+72..B+144`, payload nonce `B+144..B+168`, then authenticated ciphertext. Slot AAD is `0..B` plus the existing purpose; payload AAD is `0..B+144` plus `/payload`. Minimum size is 238 bytes plus hint bytes; the 64 MiB total limit, Argon2id profile, XChaCha20-Poly1305 and recovery HKDF profile from ADR 0006 remain unchanged.

Magic контейнера остаётся `57 50 41 53 53 00 01 00`; format равен `u16 = 2`, suite и профиль KDF остаются `1`. Первые 46 байт сохраняют поля ADR 0006. Байты `46..48` и `48..50` содержат little-endian длины UTF-8 подсказок пароля и расположения фразы. Затем следуют байты подсказок в этом порядке. При `B = 50 + passwordHintBytes + recoveryHintBytes` nonce/slot пароля занимают `B..B+72`, recovery nonce/slot `B+72..B+144`, payload nonce `B+144..B+168`, затем идёт аутентифицированный шифротекст. AAD slots состоит из `0..B` и прежнего purpose; AAD payload из `0..B+144` и `/payload`. Минимум: 238 байт плюс подсказки. Общий лимит 64 MiB, профиль Argon2id, XChaCha20-Poly1305 и recovery HKDF из ADR 0006 сохраняются.

The V2 setup requires 15 or more Unicode scalars, at most 1,024 UTF-8 bytes, an uppercase letter (Lu), lowercase letter (Ll), ASCII digit and Unicode punctuation or symbol. Native V2 creation rejects line separators. The branded single-line editor removes LF during paste; other spaces and Unicode stay exact. This replaces the earlier UI guarantee that pasted LF was retained.

Настройка V2 требует минимум 15 Unicode scalars, максимум 1024 UTF-8 байта, заглавную букву (Lu), строчную букву (Ll), ASCII-цифру и Unicode punctuation или symbol. Native создание V2 отвергает разделители строк. Фирменный однострочный редактор удаляет LF при вставке; остальные пробелы и Unicode сохраняются точно. Это заменяет прежнюю гарантию UI о сохранении вставленного LF.

Rust keeps a zeroizing setup draft. Back and password edits preserve its random entropy and recovery words. Three quiz positions reference different word values; each has one correct word and two different decoys outside the phrase. All three answers are checked again natively before encryption and atomic publication. A write with an uncertain result retains its exact candidate for retry; changed confirmation inputs are refused. Lock invalidates the draft and queued work.

Rust хранит обнуляемый черновик настройки. Возврат и изменение пароля сохраняют его случайную энтропию и recovery-слова. Три позиции проверки содержат различные значения слов; у каждой один правильный вариант и два разных отвлекающих слова вне фразы. Все три ответа повторно проверяются нативно до шифрования и атомарной записи. Неоднозначная запись сохраняет точный кандидат для повтора; изменённые параметры подтверждения отвергаются. Блокировка отменяет черновик и ожидающие операции.

Download, copy and QR are explicit plaintext exports of the same space-separated 24 words. Native TXT writes use a private temporary file and atomic replacement with mode 0600. QR encoding is local. Clipboard cleanup compares the current content and runs after 60 seconds, lock or close; clipboard history and independent exported copies cannot be revoked. A save chooser that completes after lock cannot start a native export. Destination I/O runs outside the vault state mutex and checks generation before publication. Shutdown awaits any clipboard cleanup already started by lock.

Скачивание, копирование и QR являются явным открытым экспортом одних и тех же 24 слов через пробел. Native TXT использует приватный временный файл, атомарную замену и mode 0600. QR кодируется локально. Очистка буфера сравнивает текущее содержимое и выполняется через 60 секунд, при блокировке или закрытии; история буфера и независимые экспортированные копии не отзываются. Диалог сохранения, завершённый после блокировки, не начинает native export. Запись в выбранное место выполняется вне mutex состояния сейфа с проверкой generation перед публикацией файла. Закрытие ожидает очистку буфера, уже начатую блокировкой.
