# Triage labels

| Role / Роль | Label / Метка |
| --- | --- |
| Initial evaluation / Первичная оценка | needs-triage |
| Missing information / Нужны сведения | needs-info |
| Specified implementation / Готово к реализации | ready-for-agent |
| Manual intervention / Нужно ручное участие | ready-for-human |
| Declined / Не планируется | wontfix |

Preserve existing labels; create only missing labels.
Сохраняйте существующие метки; создавайте только отсутствующие.

Blocking links determine prerequisites independently of the readiness label. An external dependency remains explicit until an immutable artifact or supported platform API is verified.

Блокирующие связи определяют предпосылки независимо от метки готовности. Внешняя зависимость остаётся явной до проверки неизменяемого артефакта или поддержанного API платформы.
